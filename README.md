# Smoke on the Stairs

A real-time rescue game about persuasion and trust. [Play](https://smoke.adamwhite.work).

Node 26.12.0 and pnpm 12.14.0. Run `pnpm install --frozen-lockfile`, `pnpm dev`. Checks: `pnpm check:lane`, `pnpm build`, `pnpm e2e`. Design: [docs/design.md](docs/design.md).

HF 3.2.0 owns the actors. PixiJS 8 draws the cut-paper stairwell. Code is MIT licensed.
