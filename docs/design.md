## Why this is a game

Movement spends time. A shout can burn trust. Staying near Sevim shows concern but delays Hacer. Burak knows something you do not: he checks the exit and returns to help Sevim without an order. Smoke waves lengthen visibly before closure. You can learn when to cross and choose whom to believe. There is no score or hidden correct dialogue sequence.
